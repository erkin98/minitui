'@minitui/agent-core': minor

The model loop handles abort, stream endings and retries: a missing finish chunk, a `length` or `content-filter` ending, the step-ceiling halt and the repeated-call halt are no longer clean finishes, and a `length` ending ends the run with a non-retriable error instead of feeding a truncated spec to validation. A cancelled turn drops its buffered events, a turn cancelled before its first pull yields none, and `cancel()` reaches every live turn. Re-runs wait 250 ms to 4 s, and construction throws a `RangeError` naming an out-of-range number. A 400, 401, 403 or 404 from the provider ends the run as a non-retriable error, and an in-stream error object shows as `type: message`. A failed tool's content is the tool's own redacted content without an `Error: ` prefix, stderr excerpts are the tail, and a session without a diagnostics port no longer prints provider warnings or stream errors. Redaction no longer slows down on long runs of blanks, and it also hides a value of eight or more characters assigned to an `api_key`, `token`, `secret` or `password` key and a web address user part of 20 or more characters. A session whose provider does not set `usesSdkLoop: true` takes the fallback loop even when `streamTextImpl` is set; that loop refuses a tool name it was not given (`constructor`, `toString` and the like included) and an input its schema rejects, and turns a failing tool dispatch into a failed result instead of ending the turn with a retriable error. `AgentConfig` gains `maxOutputTokens`, sessions and `createAiSdkProvider` take an optional diagnostics port, and `createAiSdkProvider` takes an optional `redactionPolicy`, so its stream-error record is scrubbed with the host's patterns. `Clock.sleep` changes shape, which breaks a hand-built clock. `@types/node` is now a runtime dependency. The package now declares its licence, Apache-2.0.
