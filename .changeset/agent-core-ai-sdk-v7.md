The package moves to version 7 of the AI SDK (`ai` 7.0.162, `@ai-sdk/anthropic` 4.0.96). A session now takes a `route`, the provider together with the model it runs, in place of separate `provider` and `model` fields; on the SDK loop the model must be a model object (`SdkModelV4`), so a model id string there is a compile error. `ModelProvider` is now `SdkLoopProvider | DirectProvider`, an SDK-loop provider must supply `sdkCallOptions`, and `isSdkLoopRoute` narrows a route. `AgentConfig` gains `effort` (`low`, `medium`, `high`, `xhigh` or `max`): unset, nothing is sent and the model keeps its own default; chosen, the Anthropic provider sends it as `output_config.effort`, and each model step writes a `model step` debug line with the effort and the model id. The system prompt is sent as the SDK's `instructions`, and a system row in an SDK-loop history ends the turn with a non-retriable error. A tool call the model gets wrong is reported back through the SDK's own invalid-call path with its original error; the synthetic `invalid` tool is gone, so no tool name is reserved. The endpoint is fixed at `https://api.anthropic.com/v1` whatever `ANTHROPIC_BASE_URL` says, and `createAnthropicModel` takes an optional `fetch`. `inputTokens` on `RUN_FINISHED` now counts cache reads and writes, and a finish reason of `interrupted` ends the run as a retriable error.
