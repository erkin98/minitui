New package: the session host. `createAppHost` mounts a spec that was validated already over the one shared data store, renders it through an injected renderer, and returns a session whose `done` settles only when the app is quit or finished. The host router handles the render-local actions (`setState`, `pushState`, `removeState`) against the shared store and sends the gated kinds to the injected exec dispatcher. It does not trust the kind, the name or the permission descriptor in a renderer's context: it takes the kind and the descriptor from the catalog, refuses a context that disagrees, and reads the value of every root named by either template of the descriptor from the live state before exec builds the consent text; a root with no live value is refused. The model's entrance, `dispatchFromModel`, reaches exec only through the same router and only for actions the catalog marks as callable by the model. State writes made from inside a store notification keep the writes queued before them, and an agent patch that would leave a non-object state root is refused. `bindRelaunchParams` builds a fresh seed model from a kept app's typed parameters, the stored values and the person's answers, and reports a secret value, or a value derived from one, by pointer so it can be kept out of anything written to disk.
