The hard floor covers more secret files (`id_ecdsa`, `id_dsa`, `*.p12`, `*.pfx`, `*.key`, `.pgpass`, `.pypirc`, `.vault-token`) and more network tools (`netcat`, `nc.openbsd`, `nc.traditional`, `socat`, `openssl`, `ftp`, `rsh`; `openssl` and `socat` are floored by command name, so local uses such as `openssl version` are denied too). A relative delete after a change of directory, or under a wrapper option that sets the directory or the root, asks; so do shell builtins that evaluate a quoted subscript, `ffmpeg` and `ffprobe` arguments that carry `://` or name a network protocol by its leading name (`http:host`), and the git options that run a program (`--upload-pack`, `--receive-pack`, `--exec`, `rebase -x`, `bisect run`, `submodule foreach` and similar), in every mode. The glob match runs in time proportional to pattern and subject length, and the floor reads the store directory from the host value. A request holding a control or invisible character is denied in every mode, as is one over the budget (a command above 4,096 characters, more than 32 paths, a path above 1,024 characters), and a request that is only oversize is refused with the size reason. Consent is bound to the exact command shown: a narrow 'always' covers exactly the approved command and nothing longer, deny rules win and also fire on the path and wrapper-name forms of a command, an unrecognised reply kind is a rejection, and a reply carries the id of the request it answers (a reply that names no waiting request approves nothing, and a duplicate in-flight id is refused). The grants file is a versioned envelope with mode 0600 in a 0700 directory, and an unreadable, newer or rule-breaking file means no persisted grants plus one warning. `createPermissionEngine` takes an optional diagnostics port. Gated actions are unavailable on Windows in this version. The MCP client and its schema validator are no longer declared as dependencies, since nothing imports them yet.
