Validation is one total pass: a failure result carries its first envelope as well as its last, and the state of a successful result is the parsed, deep-frozen value, so a consumer that writes to it in place now throws and must copy first. More is refused at generation: a binding with a key besides `action` and `params`, a malformed `repeat`, `on` or `watch`, `props` that is an array or absent, `children` that is not an array of strings, an element key named `constructor`, `prototype` or `__proto__`, a `repeat` target that is not an array, a pointer through the prototype or with a lenient index, a self-reference, a cycle, a shared child or a child listed twice, nesting past 64 levels, a malformed `visible` or `$cond`, a non-canonical state key and a non-object state. An unpicked picker, a directory under a `dir`-mode or mode-less picker and an object or array `copy` are now accepted. The re-prompts for compile errors, for an empty or whole-object reply and for binding-level extra keys are fixed strings with one line per schema issue, and a reply whose root and elements are present but refused (a reserved key, a value in two places or a value past the limits) gets its own fixed sentence. Terminal control characters are stripped from the action key and the stderr excerpt before a repair prompt reaches the model (carriage return, tab and line feed are kept). A long single line is no longer quadratic to buffer. `zod` is a development dependency only. The package now declares its licence, Apache-2.0.
