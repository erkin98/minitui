Consent replies carry the id of the request they answer: the reply schema requires `requestId`. Permission rules can be exact, so an approved command matches only itself. The kept-app record's state must be a JSON object. The reserved state keys (`RESERVED_JSON_KEYS`) and the JSON Pointer token decoder (`decodePointerToken`) are exported for the packages that check patches. Patch operation values nested up to 256 levels deep are accepted. The package now declares its licence, Apache-2.0.
