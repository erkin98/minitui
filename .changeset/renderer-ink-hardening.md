'@minitui/renderer-ink': minor
---

Ctrl-C now cancels: it denies a pending approval and calls the cancel callback instead of exiting through ink (new `exitOnCtrlC` mount option, off by default). Approval keys act only as a plain `y` or `a`: Ctrl and Alt chords decide nothing, and a file picker ignores them. While an approval is pending only the consent box is drawn: the screen is cleared when it opens and the app is redrawn when it closes, control, format and separator characters in the headline, command and paths appear as U+FFFD, a box taller than the terminal ends in a line asking for a larger terminal and refuses `y` and `a` until then, and a key written in the commit that first shows the prompt does nothing. Text drawn in the app drops carriage returns and invisible format characters, except the joiners and direction marks so that joined emoji and Persian and Indic text keep their shape, without changing state. A line under the app shows the last refused or failed action. Off-catalog specs are refused with the code `off-catalog`; mounting and updating also throw an `Error` with a code for a non-canonical key, a spec that is not a tree, a `watch` binding, an unbound component and an `initialState`. Progress messages reach the lifecycle, sanitised and at most 512 characters. A handler failure ends in one terminal `error` event and one diagnostics report. Tab traversal works across widgets, and state-patch errors are fixed strings. `InkRendererDeps` gains the optional `io`, `renderInk` and `diagnostics`, and `@types/node` is now a runtime dependency. The package now declares its licence, Apache-2.0.
